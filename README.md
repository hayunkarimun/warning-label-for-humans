One single-line safety warning label that should come printed on every
human being, 160 characters or fewer.

`main.py` (Python 3.13, standard library only) scores four original
candidate labels against the judge's published criteria — label form,
the turn landing in the last few words, recognition of how humans
actually behave, and fitting the line — and writes the winner to
`/output/entry.txt`. The winner is **"WARNING: This human runs on
caffeine, spite, and unread notifications. Do not shake, do not ask how
they slept, and never, ever say 'quick question.'"**: a real label's
wording, three true human fuels up front, and the punch — the two words
every human dreads hearing — saved for the very end.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
